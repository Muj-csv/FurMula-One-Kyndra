# Kyndra

> **Where the right homes meet the right animals.**

Kyndra is a pet adoption matching system designed to help shelters and adopters find better-fitting matches through **constraint-aware, two-sided stable matching**.

Unlike conventional pet recommendation systems, Kyndra does not simply rank pets for adopters. It models both sides of the adoption process: what an adopter wants and what a shelter needs in a successful placement.

Every match can be inspected, challenged, and explained.
